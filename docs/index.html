Agents

🌍 Archaeologist

Traces dependency chains upstream & downstream. Maps call graphs, detects circular deps, finds entry points.

📝 Planner

Designs multi-file refactoring plans. 6 operations: rename, extract, move, change-signature, remove, inline.

🛠 Executor

Applies plans with backup & rollback. File edits ordered bottom-to-top to preserve line numbers.

🔎 Verifier

Validates correctness: AST syntax check, reference integrity, dead code detection, test discovery.

Quick Start

pip install -e .
# Archaeology report
code-archaeology --dir . archaeology my_function

# Cross-file rename (dry run)
code-archaeology --dir . rename old_name new_name

# Full impact analysis
code-archaeology --dir . impact MyClass

# Codebase health check
code-archaeology --dir . integrity

Python API

from code_archaeology import Orchestrator

orch = Orchestrator("/path/to/project")
orch.build_graph()

# Archaeology
report = orch.archaeology("my_function")
impact = orch.impact_analysis("MyClass")

# Plan & execute
plan = orch.plan_rename("old_name", "new_name")
preview = orch.execute(plan, dry_run=True)   # Preview
result = orch.execute(plan, create_backup=True)  # Apply
